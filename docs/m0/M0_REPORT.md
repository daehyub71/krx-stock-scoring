## 4. 수급 NULL의 의미 — 항등식 검증

투자자 5부류(기관합계·외국인·기타외국인·개인·기타법인)의 순매수거래대금 합은 0이다. 2026-08-18 이후 행으로 확인:

| NULL 개수 | 행 | 나머지 합 = 0 |
|---|---|---|
| 0 | 34,765 | 34,765 (100%) — 항등식 자체 검증 |
| 1 | 18,417 | 18,417 (100%) — 이 NULL은 **정확히 0** |
| 2 | 8,010 | 8,010 (100%) |
| 3 | 1,953 | 1,953 (100%) |
| 4 | 247 | 247 (100%) |

charts `krx_client`는 투자자별 표에 종목이 없으면 NULL로 둔다(`models.py`: "표에 종목이 없으면 None"). 위 결과로 **"표에 없음 = 그 투자자 거래 없음 = 0원"**이 데이터로 확인된다. 2026-09-18 기준 2,646행 중 완전 1,440 · 증명된 0 1,206 · 미해소 **0**.

→ SPEC §5.4의 "한쪽이 NULL이면 0으로 보완하지 않는다"를 **"같은 행의 나머지 합이 0이면 NULL을 0으로 확정(`state=observed`, `note=derived_zero`), 아니면 missing"**으로 바꾸자는 제안(사용자 결정 필요). 규칙을 안 바꾸면 외국인 6점이 약 28%, 기관 5점이 약 8% 종목에서 결측 → 대거 `provisional`로 빠진다.

수급 행이 없는 116종목은 전부 `v=0`(거래정지 의심)이다 → `missing(unavailable)`이 아니라 거래정지 정책(§5.2)으로 처리.

보존: flows 07-14~(47거래일), shorting 07-27~(39거래일). 20거래일 창에 충분. **소급 검증(M6)은 수급·공매도 축을 약 2개월만 쓸 수 있다.**
